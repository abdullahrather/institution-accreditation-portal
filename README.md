# Institution Accreditation Portal

A Laravel 12 web app for running accreditation reviews of higher education institutions. Administrators, review committees and institutions each sign in to one portal and see only what their role allows.

## Features

- **Role-based access** with three roles, `admin`, `aic` (review committee) and `hei` (institution), enforced through Laravel Gates in controllers and views
- **Institutions:** register, list, edit and delete institutions
- **Accreditation applications:** institutions file applications, and the right roles can view and update them
- **User management:** admins create users and assign roles
- **Review data model:** programmes, criteria, question types, questions, visit types, committee expertise and their relations, built with Eloquent
- **Sign-in protection:** a math captcha on sign-up and sign-in, which reloads without a page refresh
- **Profile page** for the signed-in user
- **Sample data:** seeders fill every table with fictional records generated by Faker
- **CI:** GitHub Actions runs the PHPUnit suite on every push and pull request

## Tech stack

PHP 8.2+, Laravel 12, MySQL (or SQLite), Blade, AdminLTE 3, Bootstrap 4, jQuery Validation and `mews/captcha`.

## Getting started

You need PHP 8.2 or newer with the GD extension, Composer, and MySQL or SQLite.

```bash
git clone https://github.com/abdullahrather/institution-accreditation-portal.git
cd institution-accreditation-portal
composer install
cp .env.example .env
php artisan key:generate
```

Set the `DB_*` values in `.env`, then create the tables and sample data:

```bash
php artisan migrate --seed
php artisan serve
```

Open http://localhost:8000. The first page is the sign-up form, and accounts created there get the `admin` role, so you can then create users with the other roles from **Users**. Signing in as each role shows how the screens and actions change.

The roles table is filled by its migration. The seeded sample users exist to fill lists and cannot sign in.

## How access works

| Gate | Roles | Used for |
|---|---|---|
| `admin` | admin | User management and full control |
| `admin-aic` | admin, aic | Review committee screens |
| `admin-hei` | admin, hei | Institution and application screens |

The gates are defined in `app/Providers/AuthServiceProvider.php`.
